# Established EEH Infographic Style

Use this reference when a request calls for the established style or when working in the Enterprise Event Hub material.

## Visual system

- Canvas: light warm neutral, typically near parchment or off-white. For document graphics, use a horizontal 16:9-style canvas by default.
- Type: large, high-contrast ink-blue headline and dark body labels; strong editorial hierarchy.
- Structure: two to five rounded, thin-outline cards; one colored accent per concept; broad margins and deliberate whitespace.
- Visual language: use the actual official logo for every named product/service that has an available asset; use familiar flat icons only for concepts, capabilities, or unnamed services. A large numbered marker or clear zone label; slim arrows or connectors that indicate flow without dominating it.
- Close: a dark ink-blue horizontal takeaway panel with a white icon and one plain-language conclusion when the visual needs an outcome statement.

## Layout quality gate

Before delivering, inspect the generated image at full size. For a document graphic, confirm a horizontal 16:9-style canvas unless another aspect ratio was requested. Confirm every named product/service has its real, recognizable, undistorted official logo—not a generic icon. Check the outer canvas, every card edge, number badge, logo/icon, label baseline, connector endpoint, and takeaway bar for consistent alignment and comfortable padding. Correct any clipped text, unequal panels, uneven gaps, overlap, distorted logos, or logo/text collisions.

## Prompt cues

State the output requirements directly: presentation-ready horizontal infographic; off-white background; dark ink-blue typography; rounded outlined cards; actual official logos for every named product/service, supplied as image references; simple flat icons only for non-product concepts; consistent grid alignment; equal card spacing and padding; spacious layout; legible large labels; subtle arrows; no watermark; no tiny text; no stock photography; no clutter.
